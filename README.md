# BLE Remote — المرحلة 1 (Phase 1)
Sender + Receiver عبر BLE، يعملان بدون إنترنت.

## ما يعمل في هذه المرحلة
- Receiver: شاشة بيضاء نقية عند أول تشغيل، تظل كذلك حتى أمر صريح.
- Sender: كتابة نص، اختيار الحجم/لون النص/الخلفية، معاينة محلية فقط،
  وزر «إرسال واعتماد وعرض» (الوحيد الذي يغيّر شاشة Receiver) + «مسح».
- بروتوكول: تجزئة، CRC32، ACK، منع تكرار تنفيذ الأمر (id).
- Receiver يحفظ آخر محتوى معتمد ويستعيده بعد إغلاق التطبيق/إعادة التشغيل.

## البناء
1. ارفع المجلد إلى مستودع GitHub → تبويب Actions → Build APKs.
2. نزّل sender-apk و receiver-apk من Artifacts. (الخط يُنزَّل تلقائياً.)

## الاقتران
شغّل Receiver أولاً (يبدأ الإعلان تلقائياً)، ثم Sender → «بحث واتصال».

## UUIDs
Service 12345678-1234-5678-1234-56789abcdef0 / Write ...def1 / Notify ...def2

## لاحقاً (المراحل التالية)
صور وخلفيات ← خطوط ← مذكرات ← صفحات ← قوالب/مشاريع ← جدولة ← وسائط (Wi-Fi) ← أمان PIN.


## اختيار وسائط جهاز Receiver مباشرة

يمكن لتطبيق Sender تصفح الصور والفيديوهات والملفات الصوتية الموجودة في مكتبة جهاز Receiver عبر
خادم الوسائط المحلي المحمي برمز وصول. بعد اختيار ملف من Receiver:

- الفيديو والصوت يُشغّلان مباشرة من `content://` URI على جهاز Receiver باستخدام Android MediaPlayer/VideoView؛ لا يتم رفعهما إلى Sender ولا نسخهما إلى مجلد التطبيق في المسار الطبيعي.
- الصور تُنسخ محلياً إلى مجلد `received` داخل Receiver فقط لأن عنصر Kivy Image يحتاج مسار ملف؛ لا تمر الصورة عبر Wi-Fi إلى Sender.
- BLE ينقل أمر العرض ومرجع الملف فقط، بينما Wi-Fi يستخدم لتصفح قائمة الوسائط والصور المصغرة.

يتطلب ذلك منح Receiver صلاحية الوصول إلى نوع الوسائط المطلوب في إعدادات Android. إذا كانت صلاحية الصور/الفيديو محدودة على Android 14 أو أحدث، فقد لا تظهر جميع الملفات.

## BLE Remote v4 — مركز الأوامر وفهرس مكتبة المستقبل

أضيفت شاشة **مركز الأوامر النصية** في Sender. ترسل الأوامر عبر BLE، ويبحث Receiver داخل فهرس SQLite محلي لمكتبة MediaStore.

أمثلة:
- شغل فيديو الترحيب
- اعرض آخر صورة
- شغل آخر صوت
- سم الملف IMG_123.jpg باسم السيارة
- احصائيات المكتبة
- تحديث المكتبة

الفيديو والصوت يشغّلان من URI الأصلي على Receiver ولا يتم نسخ ملفهما إلى Sender. الصور تُنسخ إلى مساحة التطبيق الخاصة على Receiver عند الحاجة لعرضها بمكوّن Kivy.

تفاصيل التصميم، حدود التنفيذ، وخطة الاختبار في `ARCHITECTURE_V4_AR.md`.
